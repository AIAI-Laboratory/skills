# Agent Working Agreements

Instructions for AI agents working in this repo. User instructions take precedence over everything below.

## Commits and pushes

- Do NOT commit unless the user explicitly asks for a commit. Leave changes uncommitted in the working tree and report what would be committed.
- Do NOT push unless the user explicitly asks for a push.
- Never amend, force-push, or rewrite history without an explicit request.
- Never commit secrets (.env, credentials, private keys).

## Docs and skills

- Follow `CONTRIBUTING.md` for the contribution process and `docs/skill-anatomy.md` for the skill format.
- English only. No organization names in prose.
